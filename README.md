# 🎄 Jogos de Natal para a Ceia em Família

Página de vendas responsiva para o kit digital de 32 páginas de jogos para imprimir.

## Conteúdo
- `index.html`: página principal e checkout Wiven.
- `assets/`: cinco GIFs animados, nas seções certas: kit, bingo, cartas de desafio, pavê e Réveillon.

## Colocar o site no ar com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione **main** e **/(root)** e clique em **Save**.
4. Visite: https://jhonyv02.github.io/jogos-natal-ceia-em-familia/

Checkout configurado: https://checkout.wiven.com.br/checkout/cmwpiq83r0zeh01oot1tv1cs9?offer=7FRYPF6

Antes de anunciar, confira os cinco GIFs, o valor cobrado pelo checkout e a entrega do PDF após pagamento.
